M365 보안 프로젝트 포털 (공개용)

한글 요약파일 하나를 내려받아 브라우저에서 열면 됩니다. 설치나 서버가 필요 없고, 입력한 내용은 내 PC 밖으로 나가지 않습니다.

상황 01포털 내려받기파일 이름: M365_보안_프로젝트_포털_공개용.html본문에서 읽기 ↓상황 02진행 상황을 다른 사람과 이어서 작업하기포털은 입력한 내용을 브라우저 안에만 보관합니다. 다른 PC나 다른 사람과 이어서 작업하려면 상태 파일 저장으로 JSON 파일을 받고, 상대방이 같은 포털에서 그 파일을 불러오면 됩니다.본문에서 읽기 ↓상황 03공개용에서 빠진 내용 확인하기이 파일은 실제 프로젝트에서 쓰던 포털을 일반화한 버전입니다.본문에서 읽기 ↓

내려받기​

포털 HTML 내려받기 (약 3.2MB)

  • 파일 이름: M365_보안_프로젝트_포털_공개용.html
  • 실행 환경: 최신 Edge·Chrome·Safari. 인터넷 연결 없이도 열립니다(글꼴만 기본 글꼴로 바뀔 수 있습니다).
  • 내보내기 도구(Excel·PPT)는 파일 안에 함께 들어 있어 별도 설치가 필요 없습니다.

포털에서 하는 일​

영역내용
플랜 비교Business Basic부터 E7까지 보안 기능 범위를 비교합니다.
Copilot 도입 판단정보보호 요청사항별로 도입 가능 여부(O/X)와 조건을 정리합니다.
보안 아키텍처플랜과 구성요소를 고르면 데이터 흐름도가 바뀝니다. PNG로 저장할 수 있습니다.
고객 환경 조사·요구사항·인터뷰조사 항목과 인터뷰 기록을 남기고 요구사항으로 연결합니다.
정책 설계·작업 절차서조건부 액세스, DLP, 레이블 등 정책 초안과 적용 절차를 작성합니다.
WBS·진행 현황예정 공정표와 결정 사항을 관리하고 Excel로 내보냅니다.
보고서지금까지 정의한 내용을 PPT 3장으로 요약해 저장합니다. 필수 문서는 Word로 저장합니다.

상태 파일로 이어서 작업하기​

포털은 입력한 내용을 브라우저 안에만 보관합니다. 다른 PC나 다른 사람과 이어서 작업하려면 상태 파일 저장으로 JSON 파일을 받고, 상대방이 같은 포털에서 그 파일을 불러오면 됩니다.

  1. 작업을 마치면 상단의 상태 파일 저장을 눌러 JSON을 받습니다.
  2. JSON 파일은 메일·Teams·SharePoint 등 기존 보안 채널로 전달합니다.
  3. 받는 사람은 이 페이지에서 포털을 내려받아 열고, 상태 파일을 불러옵니다.

:::caution 상태 파일은 공개하지 마세요 상태 파일에는 조사 결과, 인터뷰 기록, 정책 초안이 그대로 들어 있습니다. 이 사이트나 공개 저장소에 올리지 말고, 프로젝트 관계자끼리만 주고받으세요. :::

공개용에서 빠진 내용​

이 파일은 실제 프로젝트에서 쓰던 포털을 일반화한 버전입니다.

  • 고객사 이름, 조직·부서명, 사업장 위치, 내부 시스템과 협력사 이름을 모두 제거했습니다.
  • 고객 환경에만 해당하던 문장은 일반 금융권·대기업 환경 기준으로 바꿨습니다. 담당 조직은 정보보안 담당처럼 역할 이름으로 표기합니다.
  • 일정, 결정 사항, 인터뷰 내용은 비어 있는 상태로 시작합니다.

적용 전 확인할 점​

  • 플랜별 기능 범위와 Copilot 데이터 처리 조건은 Microsoft 공식 문서와 계약 조건으로 다시 확인하세요. 포털의 판단표는 작성자의 정리이며 보증이 아닙니다.
  • 실제 고객에 맞춘 편집본이 필요하면 문의로 요청하세요.

한국어 요약​

M365 보안 프로젝트 포털은 브라우저에서 바로 여는 단일 HTML 파일입니다. 환경 조사부터 보고서까지 한곳에서 작성하고, 상태 파일(JSON)로 이어서 작업하며, PPT·Excel·Word로 결과물을 내보냅니다.
