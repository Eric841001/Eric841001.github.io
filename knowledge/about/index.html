Microsoft 엔터프라이즈 아키텍트

Youngsun Kang

Microsoft 365, 보안, Copilot, AI 에이전트, Azure와 마이그레이션을 설계하고, 그 결정을 실행 가능한 아키텍처와 운영 체계로 바꾸는 일을 합니다.

기술 선택을 보안 기준, 도입 로드맵, 제안 구조, 구축 계획과 재사용 가능한 운영 모델로 정리해 조직이 스스로 이어 갈 수 있게 돕습니다.

저서​

생성형 AI 도입 이후 일하는 방식을 바꾸는 과정을 정리한 책을 펴냈습니다.

저자의 책 · 신간

사람의 행동과 일하는 방식을 바꿔 AI를 성과로 만드는 법

Copilot과 생성형 AI를 들여왔는데 일하는 방식은 그대로라면, 이 책이 그다음 단계를 다룹니다. 문서가 작성·검토·승인을 거치는 실제 흐름에서 어디가 막히는지, 팀이 믿고 쓸 자료와 검토 책임을 어떻게 정하는지, 절약한 시간을 실제 성과로 증명하고 90일 뒤 다른 팀으로 넓히는 기준까지 현장의 언어로 정리했습니다.

  1. 1부AI를 도입했는데, 일은 왜 그대로일까
  2. 2부도구를 배웠다면, 이제 일하는 방식을 바꿀 차례다
  3. 3부잘 쓰던 팀도 멈춘다, 변화에는 운영이 필요하다
  4. 4부성과를 증명하고, 다음 팀에서도 작동하게 하라

전문 분야​

조직이 "어떤 기술을 쓸까"라는 질문에서 출발해 실행 가능한 아키텍처, 안전한 운영 모델, 측정 가능한 도입 성과에 이르도록 돕는 엔터프라이즈 Microsoft 아키텍트입니다.

Microsoft 365, 보안, Copilot, AI 에이전트, Azure, 마이그레이션, 사전 기술 검토와 수행 거버넌스가 만나는 지점에서 일합니다. 경영진의 의도, 업무 요구사항, 기술 통제, 구축 계획, 운영 인수인계를 하나의 흐름으로 잇는 것이 핵심입니다.

컨설팅 현장에서는 Microsoft 기술을 실제 업무, 보안 요구사항, 변화 관리, 제안 자료, 수행 산출물과 연결해 고객이 근거를 갖고 결정하고 자신 있게 운영하도록 만드는 역할을 맡습니다.

일하는 원칙​

엔터프라이즈 Microsoft 프로젝트는 아키텍처, 보안, 도입, 수행 거버넌스가 함께 움직일 때 성공합니다. 다음 네 가지 원칙으로 일합니다.

명료함읽히는 아키텍처기술 결정을 경영진, 보안 조직, IT 운영, 업무 책임자가 바로 실행할 수 있는 말로 바꿉니다.
보안증빙이 남는 설계ID, 데이터, 기기, 접근, 감사, 승인 통제를 업무 위험과 운영 책임에 연결합니다.
도입시범에서 일하는 방식으로실제 업무 장면, 챔피언, 교육, 피드백, 효과 측정을 중심으로 Copilot과 AI 도입을 설계합니다.
수행경험을 자산으로프로젝트 경험을 양식, 점검표, 플레이북, 참조 패턴으로 남겨 다음 수행의 품질을 높입니다.

공개 사이트에는 고객사 이름, 프로젝트 식별자, 테넌트 정보, 계약 정보를 싣지 않습니다. 아래는 업종과 상황별로 익명화한 진행 패턴입니다.

유통Microsoft 365 보안 정책 컨설팅Microsoft 365, Exchange Online, SharePoint, Teams, OneDrive의 보안·정책 설계와 거버넌스 통제제조Copilot 도입과 거버넌스Microsoft 365 확산, Copilot 운영 모델, 변화 관리와 거버넌스금융SaaS 보안 준비망 분리 업무 환경, Zero Trust와 규정 준수 검토물류Exchange 현대화Exchange Online 전환 계획, 보안 검토, 관리자 인수인계와 운영 전환그룹사테넌트·기기 거버넌스Entra ID, Intune, Microsoft 365 거버넌스, 기기 규정 준수와 운영 모델기업 AIAI 에이전트 운영 모델Copilot Studio 워크숍, 에이전트 후보 발굴과 통제된 수명 주기

이 지식센터를 만든 이유​

고객사, 파트너, 컨설턴트, 기술 커뮤니티가 제품 문서만으로는 얻기 어려운 실무 판단 기준을 찾을 수 있도록, 공개해도 안전한 범위에서 현장 경험을 정리한 곳입니다.

목적엔터프라이즈 Microsoft 설계를 다시 쓸 수 있게고객 기밀을 지키면서 현장 경험을 구조화된 안내로 바꾸는 것이 목표입니다.
지식설계 참고 문서Microsoft 365, 보안, Copilot, Azure, 마이그레이션, 거버넌스 설계 노트현장 교훈익명화한 성공 패턴고객 이름과 민감 정보 없이 정리한 업종·상황별 패턴자료요청형 컨설팅 양식제안, SOW, WBS, 진단, 위험 관리 대장 등 문의로 받을 수 있는 산출물AI 도입Copilot에서 에이전트까지Copilot 활용에서 Copilot Studio, Microsoft 365 에이전트, 통제된 기업 AI 운영으로 가는 길

Microsoft MVP를 향한 기여​

이 지식센터는 장기적인 Microsoft MVP 활동의 기반이기도 합니다. 목표는 직함이 아니라 기여의 품질입니다. Microsoft 고객과 기술 커뮤니티에 도움이 되는 설계 참고 문서, 공개 가능한 교훈, 실무 양식, 반복해서 쓸 수 있는 안내를 꾸준히 쌓습니다.

지식설계 노트Microsoft 365, 보안, Copilot, Azure, AI 에이전트 실무 참고 문서
패턴현장 교훈Copilot 준비, 보안 거버넌스, 마이그레이션, 변화 관리 플레이북
자료재사용 컨설팅 양식제안, SOW, WBS, 위험 관리 대장, 진단표와 수행 양식
커뮤니티공개 기여 기록익명화한 고객 성공 참조 패턴과 실무 구축 안내
