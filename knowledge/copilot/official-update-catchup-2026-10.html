Copilot 공식 업데이트 누락 점검

확인일: 2026년 10월 16일(KST). 아래는 공식 발표의 변경 목록이며, 모든 테넌트에서 즉시 사용할 수 있다는 의미는 아닙니다. 대상 앱·플랫폼, 라이선스, 지역, 단계적 배포 여부는 연결된 원문과 실제 테넌트에서 확인하세요.

10월 6일 운영 체크포인트​

  • 검색에서 채팅으로: Windows·Web의 Microsoft 365 Copilot Search 결과를 문맥으로 이어 후속 질문·요약·콘텐츠 생성을 할 수 있습니다. Web 채팅에는 Try Again과 Switch Model을 포함한 응답 재생성이 추가됐습니다. 검색 권한과 선택 모델을 포함해 대표 사용자로 단계적 배포 여부를 확인하세요.
  • 커넥터 권한 매핑: 관리자가 Microsoft 365 관리 센터의 Settings > Search & intelligence > Data sources에서 생성된 연결의 쿼리 문자열과 사용자 ID 매핑 규칙을 직접 수정할 수 있습니다. 변경 후 다음 크롤을 확인하고, 영향받는 사용자로 소스 범위와 권한 누락·과다 노출을 재검증하세요.
  • SharePoint 광범위 공유 감사: SharePoint Advanced Management 관리자는 Data access governance reports에서 Everyone과 Everyone except external users에 부여된 항목 단위 권한을 보고서로 확인할 수 있습니다. 광범위 그룹 공유 보고서 안내의 역할·모듈 전제 조건을 확인하고 사이트·파일 소유자와 예외 필요성을 같이 검토하세요.
  • PowerPoint·Cowork: Windows PowerPoint에는 사용자 정의 커스텀 스킬, Mac에는 프롬프트에서 SharePoint·OneDrive 파일명이나 소유자를 참조해 발표자료를 생성하는 기능이 추가됐습니다. Web의 Copilot Analytics·Consumption 대시보드는 Cowork 채택·영향·크레딧 소비 지표와 export, Advanced Insights의 Consumption·Person query를 제공합니다. 해당 라이선스와 분석 역할을 확인한 뒤 파일럿 기준선을 잡으세요.

9월 25일 새 Copilot 공식 발표​

Microsoft는 Copilot 앱의 새 작업 진입점으로 Home, Code, Autopilot을 발표했습니다. 이는 릴리스 노트의 전면 GA 목록이 아니라 단계적 공개 계획이므로, 도입 일정과 비용을 분리해서 판단해야 합니다.

  • Home: Chat과 Cowork를 한곳에 모으고 Word·Excel·PowerPoint 문서를 Copilot 안에서 만들고 편집하는 시작 화면입니다. 앞으로 수 주에 걸쳐 Frontier 프로그램부터 배포합니다.
  • Code: 자연어로 앱·대시보드·자동화·워크플로를 만드는 환경입니다. Frontier에 먼저 배포하고 Microsoft 365 Premium·Pro 구독자용 preview는 2026년 후반으로 안내했습니다. Copilot Managed Runtime은 현재 preview입니다.
  • Autopilot: 이전 명칭 Scout인 지속 실행형 개인 에이전트입니다. 테넌트 안에서 자체 ID·메모리·컴퓨터·작업 공간을 사용하며 9월 말 private preview 확대 대상으로 발표됐습니다.
  • 비용 구분: 일반 Chat과 Microsoft 365 앱 내 Copilot은 사용자 구독 라이선스(USL), Cowork·Code·Autopilot 같은 장기 실행 작업은 Copilot Credits 기반 사용량 과금(UBB)으로 설명했습니다. 파일럿 전에 크레딧 한도·승인·모델 정책과 감사 범위를 함께 설계하세요.

출처: Microsoft 공식 블로그 — Introducing the new Copilot with Home, Code and Autopilot.

9월 30일 후속 업데이트​

Microsoft가 9월 월간 업데이트와 별도 공식 발표로 실제 배포 범위와 관리 지점을 보완했습니다.

  • GPT-6.1 Sol·Claude Sonnet 5.5: 9월 30일부터 Cowork와 Copilot Studio에 사용량 기반 과금(UBB)으로 배포를 시작했습니다. Word·Excel·PowerPoint·Chat은 Microsoft 365 Copilot 사용자 구독 라이선스(USL) 범위에서 다음 주부터 단계적으로 배포한다고 안내했습니다. Claude 또는 일부 GPT 화면을 사용하려면 조직의 Anthropic·OpenAI 하위 처리자 설정을 확인해야 하며, 앱 내 모델별 사용 한도가 적용될 수 있습니다. 모델 공식 발표
  • Microsoft 플러그인 레지스트리: Microsoft·파트너·조직 제작 플러그인을 Copilot 앱과 Microsoft 365 앱에서 함께 찾고 배포하는 통합 카탈로그가 9월에 배포됐습니다. 관리자는 Microsoft 365 관리 센터와 Agent 365에서 플러그인을 한 번 승인하고 중앙 관리할 수 있습니다. 도입 전에는 게시자 신뢰, 연결 권한, 데이터 처리 위치, 사용자 공개 범위를 승인 기준에 포함하세요. 플러그인 레지스트리 공식 발표
  • 월간 배포 확인: Teams·Outlook의 Copilot UI, 프롬프트 안 / 에이전트·@ 스킬 호출, 스캔 PDF 검색, Android Office 편집, 모바일 Record가 9월 배포 항목으로 정리됐습니다. 관리 기능에는 Copilot Search의 신뢰할 수 있는 SharePoint 사이트를 최대 100개 지정하는 중앙 관리와 집계 단위 Pulse 설문이 포함됩니다. Edge 새 탭 통합은 10월 예정이며 일정은 변경될 수 있습니다. 9월 공식 월간 업데이트

월간 블로그의 배포 표현은 개별 테넌트의 즉시 사용 가능성을 보장하지 않습니다. 기능 표시, 라이선스, 하위 처리자·연결 정책과 메시지 센터 공지를 함께 확인하세요.

10월 9일 Copilot 앱·Notebooks 업데이트​

  • Office in Copilot: Copilot 앱의 Chat 또는 Cowork에서 시작한 Word 문서, Excel 통합 문서, PowerPoint 프레젠테이션을 대화와 나란히 열어 직접 편집하고 공동 작성할 수 있습니다. 파일은 OneDrive에 저장되어 서식, 공유 권한, 버전 기록, 민감도 레이블과 규정 준수 정책을 이어갑니다. Microsoft는 10월 9일 게시 시점에 Frontier 고객 대상 배포로 안내했으므로, 일반 공급으로 간주하지 말고 대상 사용자에게 Chat·Cowork 진입점과 공동 편집이 실제 표시되는지 확인하세요. Office in Copilot 공식 발표
  • Copilot Notebooks: 에이전트형 채팅으로 간단한 작업을 위임하고, Copilot Canvas에서 협업하며, Notebook 안에서 Word·Excel·PowerPoint 파일을 실시간 편집하거나 대화 근거로 대화형 보고서를 만드는 기능이 발표됐습니다. 공식 글이 전체 테넌트 GA를 명시한 것으로 보지 말고, Microsoft 365 Copilot 라이선스·SharePoint 또는 OneDrive 저장소와 실제 롤아웃 상태를 대표 사용자로 검증하세요. Copilot Notebooks 10월 공식 업데이트

두 업데이트 모두 기존 Office 파일의 권한과 공동 작업 경계를 그대로 사용하므로, 파일럿에서는 새 파일 생성뿐 아니라 기존 파일 열기, 외부 공유, 민감도 레이블, 버전 복원까지 함께 점검하세요.

10월 13일 간접 프롬프트 인젝션 방어 업데이트​

Microsoft는 외부 메일처럼 신뢰되지 않은 콘텐츠를 기본 모델에 그대로 전달하지 않고 격리된 제약 처리 경로에서 변환한 뒤, 출처 표시와 함께 신뢰된 콘텐츠와 합성하는 Microsoft 365 Copilot의 새 강제 적용 계층을 발표했습니다. 이는 정상 권한으로 읽을 수 있는 콘텐츠 안의 악성 지시가 모델 행동에 영향을 주는 간접 프롬프트 인젝션 위험을 낮추기 위한 방어 심층 계층입니다.

  • 적용 상태를 단정하지 마세요: 발표는 초기 투자가 외부 통신 같은 고위험 콘텐츠에 집중된다고 설명하며, 릴리스 상태와 테넌트에 따라 가용성과 동작이 달라질 수 있다고 명시합니다. 대표 사용자로 외부 메일 요약·추론 시나리오를 검증하고, Microsoft 365 Copilot 방어 심층 문서의 감사·Defender·Purview 통제를 함께 점검하세요.
  • 외부 발신자 식별: Microsoft는 CVE-2026-55145 지침과 연결해 Outlook 외부 발신자 설정을 사용하도록 안내합니다. Exchange Online에서 Set-ExternalInOutlook -Enabled $true 적용 여부와 예외 목록을 검토하세요. 표시 반영에는 24~48시간이 걸릴 수 있으며, 기존 제목 삽입 메일 흐름 규칙과 중복되지 않게 해야 합니다. Exchange PowerShell 공식 문서
  • 더 엄격한 제외가 필요하면: Microsoft Purview DLP의 Email is received from > External users 조건으로 외부 메일을 Copilot의 근거·요약·인용에서 제외할 수 있습니다. 이 기능은 preview이고 메일 본문이 아니라 발신자 도메인 메타데이터를 평가하므로, 라이선스와 실제 테넌트 롤아웃을 확인한 뒤 시뮬레이션·파일럿으로 적용하세요. Purview DLP 공식 문서

출처: Microsoft 공식 블로그 — Building Trust-Aware Controls for AI. 이 계층은 기존 권한·DLP·Defender 통제를 대체하지 않으며, 외부 콘텐츠 식별과 감사·탐지·차단 정책을 함께 운영해야 합니다.

10월 15일 Copilot for legal GA​

Microsoft는 계약 검토·초안·레드라인·플레이북 대조·조항 분석을 지원하는 20개 이상의 법률 스킬과 파트너 플러그인을 일반 공급(GA)으로 발표했습니다.

  • 대상과 라이선스: Microsoft 365 Copilot 상용 라이선스 사용자가 Word 데스크톱과 Cowork에서 사용할 수 있습니다. Word의 Legal 플러그인은 기본 활성화되며 Manage plugins & skills에서 끌 수 있고, Cowork에서는 Customize > Roles & Industry에서 Legal 플러그인을 추가합니다. 시작 가이드와 전제 조건
  • 운영 방식: Word에서는 출처 인용, 추적 변경을 이용한 레드라인, .docx 플레이북 기반 계약 검토와 선례·템플릿 기반 초안을 지원합니다. Cowork에서는 여러 계약·메일·회의·파일을 아우르는 다단계 작업을 맡길 수 있습니다. 파트너 플러그인은 Microsoft 플러그인 레지스트리를 통해 순차 배포되므로 각 플러그인의 게시자·권한·데이터 처리 조건을 별도로 승인하세요.
  • 통제와 책임: 결과는 자문용이며 법률 자문이나 전문가 판단을 대체하지 않습니다. 승인된 플레이북으로 범위를 제한하고, Word의 추적 변경을 사람이 검토하며, 민감도 레이블·접근 권한·보존 정책을 포함한 Microsoft 365 통제를 그대로 적용하세요. 투명성 문서
  • 지역·배포 확인: Microsoft 발표는 전 세계 Microsoft Copilot 고객 대상 GA라고 설명하지만, 파트너 플러그인과 세부 화면은 순차 배포될 수 있습니다. 대표 사용자의 Word 데스크톱과 Cowork에서 Legal 스킬 표시, 라이선스, 언어·지역 동작을 실제 확인하세요.

출처: Microsoft 공식 발표 — Introducing Microsoft Copilot for legal. 법률 문서와 플레이북은 실제 접근 권한 범위에서만 사용하고, 생성된 조항·인용·기한은 자격 있는 담당자가 원문과 대조해야 합니다.

Copilot Studio와 에이전트​

  • GitHub Copilot harness: 8월 3일 공식 발표에서 GA로 안내했습니다. Copilot Chat·Standard와 병행하는 실행 선택지이며, 복잡한 작업에 필요한 계획·도구·워크플로를 지원합니다. 포함 라이선스로 소비비용이 모두 면제된다고 가정하지 마세요. 공식 발표, 상세 플랫폼 가이드.
  • 9월 워크플로·평가: GitHub Copilot harness 워크플로에 PDF·Word·Excel·PowerPoint의 지정 값과 표를 구조화하는 Extract 노드가 추가됐습니다. Copilot Chat·Cowork·Researcher·Analyst 등을 호출하는 Copilot 노드는 preview이며, 연결된 Microsoft 365 사용자의 권한으로 메일·파일·일정·채팅에 접근합니다. 표준 harness에는 유해 콘텐츠 심각도 기준을 설정하는 평가 방식이 추가됐습니다. 9월 변경 목록, Copilot 노드 조건, 콘텐츠 안전 평가.
  • 9월 파일·데이터: GitHub Copilot harness 대화의 파일 첨부가 GA로 확대되어 Excel·PowerPoint·Word를 포함합니다. 첨부는 영구 지식 원본이 아니라 대화 입력이며 Purview 레이블을 지원하고, 공식 문서 기준 대화 마지막 활동 후 28일간 보관됩니다. Dataverse 테이블 지식과 Multiline Text·File 열의 비정형 추론은 상태가 다르므로 후자는 preview로 구분하세요. 첨부 파일 조건, 9월 변경 목록.
  • 8월 비용·보안: GitHub Copilot harness 기반 에이전트·워크플로·앱은 제작·미리보기·테스트·평가 단계부터 Copilot Credits를 소비하며, 토큰·도구·harness 사용이 과금 범위에 포함됩니다. 관리자는 환경별 크레딧 할당과 소비 모니터링을 준비하세요. Power Platform 관리 센터에서는 환경·환경 그룹 단위로 응답의 이미지와 URL을 모두 차단하거나 문맥상 신뢰되지 않는 항목만 차단할 수 있습니다. 사용량 기반 과금, 이미지·URL 제어.
  • 8월 지식 연결: Azure SQL·SQL Server 테이블을 지식 원본으로 사용할 수 있지만, maker 연결 권한과 데이터베이스 읽기 권한·네트워크 접근을 먼저 검증해야 합니다. Work IQ 연결은 preview이고 GitHub Copilot harness/Copilot Credits를 사용하며, 기본 읽기 전용입니다. 쓰기 작업은 관리자가 별도로 허용하고 Work IQ 전용 지출 정책을 구성해야 합니다. Azure SQL 지식 원본, Work IQ preview 조건.
  • Microsoft IQ Accelerator: Work IQ·Foundry IQ·Fabric IQ를 연결하는 공급망 참조 구현입니다. 일부 기능과 MCP 통합은 preview이며 평가·실험용 조건을 확인해야 합니다. Microsoft 공식 저장소.
  • 상태 구분: Studio What's New는 이번 조회에서 9월까지 표시했습니다. 7월의 신규 에이전트 Entra Agent ID 자동생성과 환경단위 옵트아웃 제거 이후 8월·9월 변경이 추가됐으며, 개별 기능의 preview·GA 표시는 별도로 유지하세요.
  • 한국 지역: 지역 릴리스표는 Platform 2026.6.3, UX 26.06.21-24를 표시했습니다. 오래된 표의 날짜를 현재 테넌트 배포완료 근거로 사용하지 마세요.
