제품명과 접속 주소​

Microsoft의 현재 문서에서는 Microsoft 365 Copilot을 Microsoft Copilot, Microsoft 365 Copilot Chat을 Microsoft Copilot Chat으로 안내합니다. 기존 명칭은 과거 자료와의 연결을 위해 함께 사용합니다. 앱의 기본 접속 주소도 copilot.cloud.microsoft로 변경되므로 네트워크 허용 목록을 확인하세요. 현재 제품명과 접속 요구사항을 참고합니다.

01실제 업무회의, 문서, 분석, 의사 결정, 후속 조치와 응대 업무입니다.

04M365 Agents업무 흐름 안에서 맥락에 맞게 작업을 돕고 자동화합니다.

운영 원칙거버넌스와 도입은 함께 움직여야 합니다.사용자의 업무 방식이 바뀌고, 조직이 ID, 데이터 경계, DLP, 담당자 체계, 비용, 측정을 함께 관리할 때 Copilot의 가치가 생깁니다.
거버넌스데이터와 정책 경계권한 정리, DLP, Purview, Defender 신호, 담당자 체계와 승인 경로입니다.도입업무 방식 변화역할별 시나리오, 챔피언, 관리자 루틴, 교육, 성과 공유입니다.자료재사용 양식준비도 점검표, 도입 WBS, 임원 보고 자료, 에이전트 거버넌스 점검표입니다.

2026년 7월 모델 업데이트 — 과거 기록​

Microsoft는 2026년 7월 9일 Microsoft 365 Copilot에 GPT-5.6을 발표하며, 에이전트형 처리와 처음부터 끝까지 이어지는 업무를 위한 최신 추론 모델이라고 설명했습니다. 배포 범위는 Copilot Chat, Word, Excel, PowerPoint, Copilot Cowork였습니다. 이 절은 당시 발표가 도입과 거버넌스에 준 의미를 기록으로 남긴 것입니다. 현재 모델을 고를 때는 위의 최신 모델 제공 안내를 따르세요.

사용자 경험더 깊은 추론이 필요한 시나리오초안 작성, 분석, 발표 자료 다듬기, 비교, 의사 결정 지원, 후속 업무로 사용자를 안내합니다.
모델 선택분명한 모델 안내모델 선택이 가능한 곳에서는 더 깊은 추론 작업에 언제 GPT-5.6을 쓸지 설명합니다.
도입시나리오 중심 교육교육은 기능 설명에서 초안, 분석, 결정, 후속 조치 같은 결과 중심 시나리오로 옮겨 갑니다.
거버넌스기업 경계보안, 규정 준수, 개인정보, 데이터 보호, 테넌트 제어는 계속 Microsoft 365 기업 경계 안에 있습니다.
배포단계적 제공제공 여부는 지역, 테넌트 구성, 서비스 배포 일정, 모델 선택 화면에 따라 달라질 수 있습니다.
Cowork장기 실행 업무 통제Copilot Cowork 시나리오는 확대하기 전에 담당자, 승인, 비용, 모니터링 규칙이 필요합니다.

당시 도입 프로그램에서는 이 업데이트를 챔피언 교육, 임원 시연, 프롬프트 유형, 모델 선택 안내, 출시 후 성과 측정에 반영하도록 권했습니다.

공식 출처(2026년 7월 12일 한국 시간 기준 확인): Available today: OpenAI’s GPT-5.6 in Microsoft 365 Copilot

2026 Copilot Studio 업데이트​

Copilot Studio는 챗봇 제작 도구가 아니라 기업용 에이전트 플랫폼으로 다뤄야 합니다. 계획에는 새 에이전트 환경, Work IQ, 스킬, 메모리, 컴퓨터 사용, 에이전트 목록, Microsoft Entra 에이전트 ID, 에이전트 간 연결, Copilot Credit 예측을 포함하세요.

발굴에이전트 포트폴리오 접수에이전트 아이디어, 업무 담당자, 데이터 원본, 기대 효과, 위험 수준을 모읍니다.
설계스킬과 워크플로재사용할 스킬, 메모리 경계, 커넥터, 도구, 워크플로, 에스컬레이션 경로를 정합니다.
관리ID와 정책Entra 에이전트 ID, 접근 권한, DLP, 환경 전략, 승인과 감사 요구를 검토합니다.
운영비용과 측정사용량, Copilot Credit 예측, 품질, 담당자 검토, 폐기 기준을 추적합니다.

대규모 에이전트 프로그램을 설계하기 전에 Copilot Studio 2026 플랫폼 변경부터 읽으세요.

Copilot 도입 모델​

준비테넌트·데이터·보안 기준준비도 보고서, 위험 기록, 과도한 공유 검토, 시범 기준을 만듭니다.
활용 사례역할과 업무 시나리오 설계활용 사례 목록, 사용자 유형 지도, 가치 가설, 프롬프트 유형을 만듭니다.
시범 적용가치와 지원 요구 검증시범 계획, 교육 자료, 의견 대시보드, 문제 분류 주기를 운영합니다.
거버넌스데이터·프롬프트·에이전트·라이선스 관리거버넌스 헌장, 정책 모델, 담당자 체계, 비용 추적 방법을 만듭니다.
확산통제를 잃지 않고 확대배포 로드맵, KPI 모델, 운영 주기, 임원 성과 보고를 사용합니다.

다루는 주제​

준비Microsoft 365 Copilot 도입 준비테넌트, 데이터, 권한, 보안, 시범 준비 상태를 검토합니다.도입도입 프로그램 설계활용 사례 정리, 챔피언 모델, 관리자 루틴, 성과 측정입니다.거버넌스Copilot 거버넌스데이터 보호, 정책, 담당자 체계, 프롬프트 안내, 점검 주기입니다.StudioCopilot Studio 플랫폼 변경에이전트 플랫폼 계획, 스킬, 메모리, 목록, ID, 비용 예측입니다.에이전트AI 에이전트 운영 모델Agent Factory, 수명 주기, 포트폴리오 거버넌스, 다중 에이전트 구조입니다.CoworkCowork 비용 거버넌스장기 실행 업무, 승인, 담당자, 비용, 측정 통제입니다.

추천 문서​

시작Copilot 도입 준비테넌트, 보안, 데이터, 시범 기준을 준비합니다.활용 사례업무 활용 사례기능을 업무 시나리오와 도입 사례로 바꿉니다.에이전트에이전트 팩토리 운영 모델흩어진 실험 대신 관리되는 에이전트 포트폴리오를 만듭니다.참고 사례기업 AI 에이전트 팩토리 사례기업 에이전트 프로그램의 익명화한 수행 방식입니다.프로그램기업 AI 도입 프로그램전략, 변화 관리, 측정 가능한 성과를 연결합니다.요청문의와 자료 요청준비도 워크북, 도입 로드맵, 임원용 AI 가치 자료를 요청할 수 있습니다.

수행 자료​

준비Copilot 준비도 점검표테넌트, 데이터, 권한, 보안, 시범 그룹, 위험을 검토합니다.
도입도입 WBS와 일정 계획작업 흐름, 일정, 교육, 챔피언, 커뮤니케이션, 성과 추적입니다.

거버넌스데이터 보호 점검표과도한 공유, Purview, DLP, Defender 신호, 담당자와 승인 통제입니다.
에이전트에이전트 거버넌스 점검표에이전트 접수, 담당자, 수명 주기, 환경, 커넥터, 비용, 모니터링 통제입니다.
가치투자 효과와 성과 추적 모델절약한 시간, 품질, 사용량, 신뢰도, 업무 성과, 위험 감소를 측정합니다.

한국어 요약​

Microsoft 365 Copilot을 도입하기 전에 자료의 공유 권한, 보안 정책과 실제로 맡길 업무를 확인합니다.

사용자 교육과 지원, 비용 관리와 성과 측정 방법을 정한 뒤 시범 적용합니다. Copilot Studio나 Cowork로 업무를 넓힐 때는 각각의 권한과 과금 조건을 다시 확인하세요.

현재 모델 안내는 최신 모델 제공 기록을 기준으로 확인하세요. 9월 30일 발표된 GPT-6.1 Sol·Claude Sonnet 5.5도 앱별 배포 일정·라이선스·조직 정책이 다르므로 실제 사용자 화면과 함께 검증해야 합니다. 위 7월 GPT-5.6 섹션은 당시 발표를 보존한 기록입니다.

Copilot Studio와 M365 Agents를 배포할 때는 에이전트 목록과 담당자, 변경·폐기 절차, 비용과 모니터링 기준을 정합니다. Copilot Cowork처럼 장기 실행 업무로 확장될수록 승인, 책임자, 비용 통제, 품질 측정이 더 중요해집니다.
