Microsoft Autopilot (구 Scout)

Current name and availability — 2026-11-18​

Microsoft announced Autopilot, previously called Scout, on 2026-09-25 as an expanded private preview. The October 30 monthly update announced a November Frontier rollout, and the November 17 update confirmed that rollout had started for eligible Frontier customers. This is not general availability or a guarantee that it is enabled in your tenant. Eligibility requires Frontier enrollment, a Copilot license, usage-based billing, and the required management and security capabilities. Existing Scout URLs and section anchors are retained for older links. The guide uses the current name while retaining earlier Scout URLs. Architectural patterns below are not a promise that every listed action is available in a production tenant.

For a pilot, confirm eligibility, identity, permissions, approval boundaries, audit visibility and the current commercial/consumption terms. A proposed coordinator/specialist integration remains a design example until its actual connectors and runtime are validated.

Executive Summary​

Microsoft Autopilot is Microsoft's always-on personal agent concept introduced for the next stage of Microsoft 365 AI experiences.

Autopilot is a persistent personal-agent experience. Other Copilot experiences also support delegated or scheduled work; compare the specific experience and available permissions rather than treating all Copilot interactions as manual chat.

What is Microsoft Autopilot​

Microsoft Autopilot is an autonomous personal work agent.

The announcement describes a cloud-hosted agent with its own identity, memory, computer and workspace in the tenant. A user supplies its role, goal and boundaries; examples include following channels, recurring work and supplier-review coordination. Access to a particular mailbox, application or action depends on the preview configuration and granted permissions.

Scheduled tasks and legacy prompts have different controls. New scheduled tasks require a Microsoft Copilot license, support up to 10 active and 50 total schedules per user, and keep task data within the Microsoft 365 compliance boundary. They do not use Power Platform and are not controlled by the Office connected-experiences policy. Current administrator guidance.

The current user guide places management in Task Hub → Scheduled and limits the initial release to Copilot on the web and desktop; Teams, Outlook and mobile are not included. Home is still rolling out, so the visible interface can differ. Older Work IQ-tab instructions should not be used as the navigation for the new Task Hub experience.

Legacy Power Platform scheduled prompts retire on December 31, 2026. Recreate schedules that must continue as new scheduled tasks before that date. Earlier responses remain in chat history. The connected-experiences setting still applies to legacy prompts until retirement: disabling it hides their management UI but does not immediately stop existing schedules. It does not disable new scheduled tasks.

Core Capabilities​

The sections below are proposed pilot workflows. The announcement demonstrates meeting preparation and follow-up as part of a supplier-review process; it does not guarantee every calendar, mail or task action listed here in every preview tenant. Confirm the required tools and approval behavior before assigning each workflow.

Meeting Preparation​

A meeting-preparation pilot could:

  • Review meeting context
  • Read related emails
  • Review Teams conversations
  • Generate preparation materials

Calendar Coordination​

A configured pilot could:

  • Detect scheduling conflicts
  • Coordinate across time zones
  • Suggest optimal meeting times

Task Management​

A configured pilot could:

  • Track commitments
  • Monitor action items
  • Generate follow-up reminders

Email Assistance​

An email-assistance pilot could review permitted sources such as:

  • Important emails
  • Escalations
  • Outstanding requests

and highlight items requiring attention.

Work IQ Integration​

Microsoft describes Autopilot as built on Microsoft IQ. Work IQ supplies work context within that broader platform. Relevant context can include:

  • Organizational context
  • User behavior understanding
  • Enterprise knowledge grounding
  • Business relationship mapping

This enables Autopilot-like agent experiences to understand not only data but also business context.

Security and Compliance​

Microsoft positions Autopilot as an enterprise-grade agent.

Validate the applicable controls and their coverage during the pilot:

  • Microsoft Purview
  • Microsoft Defender
  • Policy Enforcement
  • Audit Logging
  • Enterprise Compliance Controls

Autopilot-style enterprise agents should run within Microsoft security boundaries and governance frameworks.

Strategic Impact​

Evaluate Autopilot against recurring tasks, review effort, completion quality and usage costs.

Traditional model:

User -> AI

Future model:

AI -> User

The announced design supports persistent work within user-defined boundaries. Test when the preview requests input and how it reports failures or incomplete work.

Future Outlook​

Possible design directions to evaluate, rather than announced delivery commitments:

  • Multi-Agent Collaboration
  • Persistent Memory
  • Cross-Application Automation
  • Autonomous Business Processes
  • Enterprise Digital Assistants

These directions do not establish general availability or support for a specific integration.

한국어 요약​

Microsoft는 Scout의 이름을 Autopilot으로 바꾸고, 2026년 11월 17일부터 자격을 갖춘 Frontier 고객에게 순차 배포하기 시작했습니다. 일반 공급 단계는 아닙니다. Frontier 등록, Copilot 라이선스, 사용량 기반 과금과 필수 관리·보안 기능이 필요합니다. 11월 17일 공식 발표를 확인하고, 문서의 업무 예시는 실제로 사용할 수 있는 도구와 권한 범위 안에서 시험하세요.

시범 도입 자격과 비용을 확인하고, 에이전트가 읽을 자료와 실행할 작업, 담당자 승인과 기록 보관 방법을 정합니다.
