이 영역은 Microsoft 365, 보안, 규정 준수, Entra, Intune, Defender, Purview, Copilot 라이선스 결정을 업무 가치 관점에서 비교합니다. 라이선스 판단은 비용을 아키텍처, 보안 통제, 도입 준비도, 운영 가치와 연결해야 합니다. 제품 이름만 비교한 결정은 근거가 약합니다.

사용자 유형사용자 유형부터 나누기플랜을 고르기 전에 사무직, 현장직, 관리자, 보안 담당, Copilot 사용자를 구분합니다.
필요 기능필요한 기능 정리ID, 기기, Defender, Purview, 협업, Copilot 요구사항을 비교합니다.
결정설명 가능한 로드맵 만들기당장 필요한 것, 향후 로드맵, 추가 기능, 운영 전제 조건을 나눕니다.

라이선스 구성 비교​

Microsoft 공식 비교에 따르면 Microsoft 365 E7은 E5에 Microsoft 365 Copilot·Microsoft Entra Suite·Agent 365를 묶은 구성입니다. E3·E5·E7 비교에서 포함 기능, E5+Copilot과의 차이, Teams 구성과 비용을 함께 확인하세요.

  • E3·E5·E7 모두 Teams 포함·미포함 상품과 이용 지역, 구매 경로와 계약 조건을 확인합니다.
  • 웹 기반 Copilot Chat과 회사 자료를 참조하는 Microsoft 365 Copilot을 구분합니다. E3·E5에서는 업무용 Copilot 추가 구독을, E7에서는 포함된 구독과 별도 사용량 요금을 확인합니다.
  • 조건부 액세스에는 일반적으로 Entra ID P1이 필요하고, 사용자·로그인 위험 정책에는 P2가 필요합니다. 에이전트 정책은 라이선스와 미리 보기 조건이 따로 있습니다. 조건부 액세스 안내를 참고하세요.
  • 미국 가격 페이지는 국내 견적이 아닙니다. 실제 제안의 통화, 세금, 약정, 지역, 갱신 조건을 확인하세요.

해외 지사의 데이터를 별도 지역에 보관하려면​

Microsoft 365 Multi-Geo는 하나의 테넌트에서 대상 서비스의 데이터를 여러 지역에 보관하는 사용자별 추가 라이선스입니다. 먼저 계약에서 Multi-Geo 구매 자격이 있는 사용자 수를 확인하고, 위성 지역에 데이터를 보관할 사용자를 셉니다. 최소 구매량은 구매 자격이 있는 사용자의 5%이며, 위성 지역에 배치할 사용자마다 라이선스가 필요합니다.

예를 들어 구매 자격이 있는 사용자가 2,000명이면 최소 구매량은 100개입니다. 위성 지역에 배치할 사용자가 150명이면 150개가 필요합니다. 공유 사서함이나 SharePoint 사이트에는 별도의 Multi-Geo 라이선스를 구매하지 않습니다. 배치할 때는 서비스별 지원 범위와 대상 지역 코드를 확인하세요. Microsoft 365 Multi-Geo 구매 및 배치 요건

한국어 요약​

Microsoft 365와 보안·Copilot 기능의 라이선스 조건을 확인하는 자료입니다.

사용자 업무와 필요한 기능, 기기 관리와 보안 요구사항을 정한 뒤 기존 구독과 추가 기능을 비교하세요. 실제 서비스 플랜과 계약 조건을 확인한 뒤 구매안을 결정합니다.

포함 기능 변화 살피기​

Microsoft 365 갱신이나 Copilot 확대를 논의할 때는 포함 기능 검토를 함께 해야 합니다. 포함된 서비스 플랜, 사용자별로 켜진 기능, Defender·Purview·Entra·Intune 통제, Copilot 준비도, 에이전트 사용량을 분명히 보여 주세요. 먼저 읽을 문서: Microsoft 라이선스 기능 변경

검토 순서​

  1. 사업과 규제상의 동인을 확인합니다.
  2. 필요한 통제를 Microsoft 워크로드에 연결합니다.
  3. 필수 보안 통제와 선택적 생산성 기능을 나눕니다.
  4. 도입 범위와 단계별 라이선스 할당을 추정합니다.
  5. 성과 지표와 활용률 검토 주기를 정합니다.

자주 쓰는 구성​

구성맞는 경우주의할 점
E3 기본 + E5 추가 기능안정적인 업무 기반 위에 일부 고급 통제만 필요한 조직추가 기능이 늘어나면 관리가 어려워집니다
E3·E5·E7 혼합사용자별로 기본 관리·고급 보호·Copilot·에이전트 관리 요구가 다름실제 사용할 기능과 적용 대상을 기록
Business Premium강한 기본 보안과 기기 관리가 필요한 소규모 조직고급 규정 준수·분석 요구는 충족하지 못할 수 있습니다
Copilot 단계적 할당전면 확대 전에 효과를 측정하려는 조직활용 사례, 교육, 데이터 준비를 먼저 갖춰야 합니다
보안 중심 E5 도입보안 현대화, XDR, DLP, 감사, 내부자 위험이 핵심 동인인 조직재무 담당에게 가치와 위험 근거를 설명해야 합니다
