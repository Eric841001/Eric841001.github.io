Defender for Endpoint macOS 온보딩

MDE MACOS ONBOARDING

Bring Mac endpoints into the same Defender operating model

macOS onboarding should align Intune management, Defender sensor health, system extension permissions, inventory visibility and XDR incident context.

MacDevice
MDMIntune
MDESensor
XDRSignal

Executive Summary​

This guide describes the onboarding process for macOS devices into Microsoft Defender for Endpoint (MDE).

The objective is to provide centralized endpoint visibility, threat detection, vulnerability management and incident response capabilities for macOS devices.

Business Scenario​

Organizations commonly require:

  • Corporate MacBook management
  • Security monitoring
  • Threat detection
  • Device inventory
  • Vulnerability management
  • Zero Trust compliance

Customer Impact​

IssueBusiness Impact
unmanaged Mac devicesweak visibility for executives, developers and creative teams using macOS
no unified endpoint signalDefender XDR incidents may miss macOS context
inconsistent security baselineantivirus, EDR, network protection and device control may vary by device
manual onboardingrollout quality depends on local administrator action
missing validation evidencesecurity and audit teams cannot prove coverage

Defender 배포 요구 사항은 최근 세 가지 정식 macOS 버전인 15·26·27을 지원 대상으로 명시합니다. 릴리스 기록에는 여전히 14 이상이라는 문구가 남아 있으므로, 이 안내만으로 Sonoma 14를 지원 대상으로 판단하지 마세요. 신규 배포는 요구 사항에 명시된 버전을 기준으로 준비합니다. Intune 관리 지원 OS는 Intune 지원 플랫폼에서 별도로 확인하세요. 두 제품을 함께 사용할 때에는 양쪽 조건을 모두 만족해야 하며, CPU 아키텍처 지원이 모든 OS 버전 지원을 뜻하지는 않습니다.

10~11월 에이전트 변경​

11월 GA 빌드 101.26092.0012는 오류와 성능을 개선한 버전입니다. 릴리스 버전은 20.126092.12.0이며, 최신 릴리스 기록에서 배포 버전을 확인하세요.

10월 추가 GA 빌드 101.26092.0009에는 다음 변경이 포함됩니다.

  • Device Control v1 종료: v1 정책을 쓰는 기기는 v2 전환이 필요합니다. macOS USB 제어 문서에서 v2 구성과 실제 동작을 확인하는 순서를 설명합니다.
  • 보호 상태와 안정성: 보호 엔진 연결과 시스템 확장 구성의 상태 보고, 서비스 안정성과 대량 파일 작업 시 CPU 사용을 개선했습니다. 업데이트 후 설치 버전과 보호 엔진·시스템 확장 상태를 점검하세요.
  • EDR: 시작·절전 해제 후 인증과 macOS 기기 격리를 개선했습니다.

101.26082.0012에는 Bluetooth 권한 상태 보고, 키보드 접근성 개선과 AI 에이전트 런타임 보호 설정 지원이 기록돼 있습니다. 런타임 보호 설정 지원을 101.26092.0009의 신규 항목으로 구분하지 마세요. 빌드 설치만으로 보호가 활성화되거나 별도 사용 권한이 부여되지는 않습니다. 권한 상태가 표시되더라도 필요한 접근 권한은 기기에서 별도로 점검해야 합니다.

출처: Microsoft의 10월 추가 macOS 릴리스, GA 제공 상태. 지원 OS 조건과 Intune의 관리 조건은 각각 확인해야 합니다.

Architecture​

macOS onboarding architectureManaged Mac to Defender XDR
01macOS deviceCorporate MacBook or managed macOS endpoint enters the onboarding scope.
02Intune managementDeploy configuration profiles, system extensions, permissions and compliance settings.
03Defender sensorInstall and validate Microsoft Defender for Endpoint sensor health and connectivity.
04Defender XDRConfirm inventory, alerts, vulnerability signals and incident correlation.

Deployment Models​

ModelBest ForNotes
Intune Managed DeploymentMicrosoft 365 managed endpoint environmentsrecommended default for policy consistency and reporting
Manual Deploymentsmall pilots or break-glass validationnot recommended for production scale
Jamf + Defender Integrationestablished Jamf-based macOS fleetsalign Jamf ownership with Defender security operations

Required Components​

  • A license that covers the capabilities being deployed; Defender for Endpoint P1 alone does not include EDR or the core vulnerability management capabilities of P2
  • Intune (Recommended)
  • Microsoft Defender Portal Access
  • Network Connectivity

The EDR and vulnerability-management checks below apply when the device has the required entitlement, such as Defender for Endpoint P2. Confirm the chosen plan and macOS feature support separately; installing the client does not add missing licenses. See Microsoft Defender licensing guidance.

Onboarding Workflow​

Onboarding workflowPrepare, deploy, validate
01Prepare tenantConfirm Defender portal settings, Intune enrollment, assignments and support scope.
02Deploy clientCreate onboarding package and deploy Defender client with required profiles.
03Validate deviceCheck sensor health, system extensions, permissions and portal inventory.
04Monitor eventsReview security events, vulnerability data, compliance status and support issues.

Validation​

Verify:

  • Device visible in Defender Portal
  • Sensor healthy
  • AV enabled
  • EDR enabled and reporting where the assigned plan includes EDR
  • Device inventory updated
  • macOS compliance result and Conditional Access outcome checked separately from Defender onboarding
  • test detection or test alert reviewed by security operations

Defender onboarding does not by itself establish Intune compliance or configure Conditional Access. Build the access policy from the supported macOS compliance settings, such as OS version, System Integrity Protection and encryption. The Defender device-risk walkthrough is scoped to Windows; do not copy its machine-risk setting into a macOS checklist without a supported integration.

사용자 없이 등록한 macOS 기기는 Intune 준수 평가를 지원하지 않습니다. 공용·무인 기기에 위 절차를 그대로 적용하지 말고 등록 방식과 접근 정책을 먼저 확인하세요. 또한 준수 정책에서 암호를 필수로 지정하면 LAPS·Platform SSO 계정을 포함한 기존 계정 암호가 만료될 수 있습니다. Microsoft는 암호 관리를 설정 카탈로그 정책으로 구성하고 Change At Next Auth를 False로 지정하도록 권고합니다. macOS 준수 설정의 적용 범위와 암호 주의 사항을 확인한 뒤 시험 기기에 먼저 적용하세요.

Acceptance Criteria​

AreaAcceptance Criteria
onboardingtarget macOS devices appear in Microsoft Defender portal with healthy sensor state
policyantivirus, EDR and relevant configuration profiles are assigned successfully
operationssecurity team can review the timeline, alerts and vulnerability data included in the assigned plan and supported on macOS
compliancethe assigned macOS compliance policy and Conditional Access policy produce the expected access decision
documentationpilot validation report and operations runbook are handed over

Operational Checklist​

  • Device onboarded
  • Security policy assigned
  • Tamper protection enabled
  • Vulnerability assessment active for the licensed, supported capabilities
  • Test alert generated
  • ownership model confirmed between endpoint, security and helpdesk teams
  • exception process documented for unsupported or unmanaged devices

Deliverables​

  • macOS Onboarding Design
  • Pilot Validation Report
  • Security Baseline
  • Operations Runbook

한국어 요약​

macOS에 Defender for Endpoint를 설치하고 필요한 권한과 조직 등록을 설정하는 절차입니다.

지원 OS와 앱 버전을 확인하고 시스템 확장, 디스크 접근 권한과 정책 적용 결과를 시험하세요. 설치 완료만으로 보호와 등록이 끝났다고 판단하지 않습니다.
