Intune macOS USB Device Control

Executive Summary​

macOS endpoints require a different device control model compared to Windows.

Defender for Endpoint and Intune can provide USB governance and removable media restrictions.

The design should start with audit mode, approved device requirements and user exception handling before enforcement. macOS controls must be tested carefully because user productivity, creative workflows and device ownership models vary widely.

한국어 요약​

macOS에서 USB 저장장치의 사용을 제한할 때 확인할 Defender for Endpoint와 Intune 설정을 정리했습니다.

사용 기록을 먼저 수집하고 승인 장치 목록, 읽기 전용과 차단 정책을 시험합니다. macOS와 Defender 버전별 지원 범위는 본문에 연결된 공식 자료에서 확인하세요.

Defender 릴리스·지원 기준은 macOS 14 이상을 안내하며 Ventura는 지원 범위 밖입니다. 이는 Defender 에이전트 기준입니다. Intune 관리 지원 OS는 Intune 지원 플랫폼에서 별도로 확인하세요. 두 제품을 함께 사용할 때에는 양쪽 조건을 모두 만족해야 하며, CPU 아키텍처 지원이 모든 OS 버전 지원을 뜻하지는 않습니다.

Device Control v1 종료와 v2 확인​

macOS Defender 빌드 101.26092.0009의 릴리스 안내는 기존 Device Control v1 종료를 명시합니다. 이전 구성 프로필의 사용 여부를 확인하고, 현재 JSON 정책으로 전환할 계획을 세우세요.

먼저 대상 Mac에서 다음 읽기 전용 명령으로 적용 상태를 확인합니다.

mdatp health --details device_control
확인 항목정상 구성에서 확인할 값과 조치
activev2가 활성화됐는지 확인합니다. v1만 표시되거나 v1·v2가 함께 보이면 이전 구성 프로필도 점검합니다.
v2_configured · v2_state각각 true와 enabled인지 확인합니다.
v2_sensor_connectioncreated_ok인지 확인합니다.
v2_full_disk_accessapproved인지 확인합니다. 권한이 부족하면 일부 또는 전체 작업을 막지 못할 수 있습니다.

정책 JSON을 검증한 뒤 Intune 또는 Jamf로 소수 기기에 배포하고, 허용·차단·감사 대상 USB 작업을 실제로 시험하세요. v2 적용 결과를 확인한 후 관리 도구에서 이전 v1 구성을 정리합니다. MDM이 정책을 관리하는 운영 기기에 로컬 시험 정책을 덮어쓰지 마세요. 현재 구성·검증 절차는 수동 적용을 사전 시험 환경으로 한정합니다.

Control Options​

macOS uses a Defender Device Control JSON policy rather than the Windows Device Control profile. Validate the JSON against Microsoft's schema, then run mdatp device-control policy validate --path <policy-file> on a test Mac before Intune or Jamf deployment. See the macOS policy deployment procedure.

  • Read Only

Recommended Architecture​

macOS USB control pathAudit before enforcement
01macOS deviceCorporate Mac endpoint enters removable media governance scope.
02Intune assignmentAssign configuration to pilot groups and validate user impact.
03Defender controlApply audit, block, read-only or approved device rules through Defender for Endpoint.
04Exception governanceReview bypass needs, creative workflows, evidence and exception expiry.

Common Risks​

  • Enforcing USB block without knowing business-critical devices
  • Treating macOS and Windows device control as identical
  • Not documenting exception approval and expiry
  • Missing user communication for blocked removable media
