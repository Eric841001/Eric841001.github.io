## 포털이 다루는 범위

실제 Microsoft 365 보안 프로젝트를 진행하며 만든 작업 도구입니다. 조사에서 보고까지 흩어지기 쉬운 산출물을 한 화면에서 이어 갑니다.

| 영역 | 내용 |
| --- | --- |
| 플랜 비교 | Business Basic부터 E7까지 보안 기능 범위를 비교합니다. |
| Copilot 도입 판단 | 정보보호 요청사항별로 도입 가능 여부와 조건을 정리합니다. |
| 보안 아키텍처 | 플랜과 구성요소를 고르면 데이터 흐름도가 바뀝니다. |
| 고객 환경 조사·요구사항·인터뷰 | 조사 항목과 인터뷰 기록을 요구사항으로 연결합니다. |
| 정책 설계·작업 절차서 | 조건부 액세스, DLP, 레이블 등 정책 초안과 적용 절차를 작성합니다. |
| WBS·진행 현황 | 예정 공정표와 결정 사항을 관리합니다. |
| 보고서 | 정의한 내용을 경영진 보고용 PPT와 문서로 정리합니다. |

## 브리핑에서 다루는 내용

- 금융권·대기업 환경에서 보안 요구사항을 정책과 공정표로 바꾸는 순서
- Copilot 도입 판단표를 정보보호 조직과 함께 쓰는 방법
- 플랜 선택에 따라 달라지는 보안 아키텍처와 데이터 흐름
- 프로젝트 단계별 산출물과 경영진 보고 구성
- 조직 환경에 맞춘 포털 구성과 적용 범위

:::note 파일은 공개하지 않습니다
포털 파일과 설계서 원본은 공개 다운로드로 제공하지 않습니다. 프로젝트 상황을 듣고 필요한 범위에 맞춰 브리핑과 적용 방법을 안내합니다.
:::
