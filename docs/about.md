## Professional Profile

Youngsun helps organizations design secure, scalable and AI-ready digital workplaces using Microsoft technologies. The work spans strategy, architecture, assessment, proposal development, implementation planning, governance and operational handover.

The primary focus is not only technical configuration. It is the full consulting path from business problem to target architecture, from SOW to WBS, and from pilot adoption to enterprise-scale operation.
