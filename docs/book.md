# AI 도입의 승부는 변화관리다

<BookFeature variant="page" />

## 이 책이 답하는 질문 {/* #questions */}

직원이 AI로 보고서 초안을 한 시간 빨리 써도, 검토하는 사람이 두 시간을 더 쓴다면 팀의 일은 나아진 것일까요. 이 책은 라이선스를 배포한 다음에 실제로 부딪히는 질문에서 출발합니다.

- 문서가 작성자에서 검토자, 승인자로 넘어가는 흐름 중 어디에서 시간이 새는가
- 팀이 믿고 쓸 자료는 어디에 두고, AI가 만든 결과는 누가 확인하는가
- 같은 문의가 반복될 때 무엇을 고쳐야 하는가
- 절약한 시간과 실제 비용 절감을 어떻게 구분해 보고하는가
- 90일 시범 운영 뒤, 어떤 근거로 다른 팀까지 넓힐지 결정하는가

## 이런 분께 권합니다 {/* #readers */}

| 독자 | 이 책이 필요한 순간 |
| --- | --- |
| 경영진·CIO | 절약한 시간과 실제 비용 절감을 구분하고, 확대 여부를 판단할 근거가 필요할 때 |
| AI·DX 추진 담당 | 라이선스를 배포한 뒤 활용이 늘지 않아 다음 단계를 설계해야 할 때 |
| 팀장·실무 리더 | 팀의 검토·승인 흐름을 바꿔 AI가 실제로 일을 줄이게 하고 싶을 때 |

## 구성 {/* #contents */}

1. **1부 AI를 도입했는데, 일은 왜 그대로일까** — 도입 직후 성과가 보이지 않는 이유를 업무 흐름에서 찾습니다.
2. **2부 도구를 배웠다면, 이제 일하는 방식을 바꿀 차례다** — 자료, 검토 책임, 승인 단계를 다시 짭니다.
3. **3부 잘 쓰던 팀도 멈춘다, 변화에는 운영이 필요하다** — 초기 열기가 식은 뒤에도 활용이 이어지게 하는 운영 방법입니다.
4. **4부 성과를 증명하고, 다음 팀에서도 작동하게 하라** — 효과를 측정하고 확대를 결정하는 기준입니다.
5. **부록** — 바로 쓸 수 있는 실행 양식과 참고 자료입니다.
