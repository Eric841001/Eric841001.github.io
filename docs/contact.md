# Contact and Asset Request

This Knowledge Center is designed for visitors who want to understand Youngsun Kang's Microsoft enterprise architecture work, review reusable consulting patterns and request the right follow-up material.

Use this page when you reached the site from an email signature, GitHub profile, LinkedIn profile or shared project reference.

## What You Can Review Publicly

The public site provides architecture and consulting guidance that can be reviewed without exposing customer-specific information.

| Area | Public Content |

| Security | Zero Trust, Conditional Access, Defender, Purview, DLP and governance patterns |

## What Can Be Requested

Editable or customer-ready materials are not posted directly on the public site. They can be shared after confirming the business context and confidentiality boundary.

Typical request examples:

- Microsoft 365 assessment workbook
- Copilot readiness checklist
- Copilot adoption WBS
- Copilot Studio or AI Agent workshop outline
- Agent Factory operating model template
- Security baseline checklist
- Exchange Online security review template
- Migration pre-assessment checklist
- SOW, WBS, risk register or executive summary template
- Sanitized customer success reference pattern

## Request Information to Include

When requesting a document or discussion, include the following context:

| Question | Example |
|---|---|
| Target workload | Microsoft 365, Security, Copilot, AI Agent, Azure, Migration |
| Purpose | presales review, architecture workshop, proposal, implementation planning |
| Industry context | manufacturing, finance, logistics, retail, healthcare, enterprise group |
| Expected output | checklist, SOW, WBS, architecture note, governance model, workshop deck |
| Confidentiality boundary | public reference, sanitized sample, internal review only |
