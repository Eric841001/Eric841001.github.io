# Downloads

This page provides a quick entry point to reusable enterprise consulting assets.

Use the [Downloads Center](./downloads/overview) for structured templates, assessment assets and delivery workbooks.

## Core Assets

- [Discovery Questionnaire](./downloads/discovery-questionnaire)
- [M365 Assessment Workbook](./downloads/m365-assessment-workbook)
- [SOW Template](./downloads/downloads-sow-template)
- [WBS Template](./downloads/downloads-wbs-template)
- [Risk Register Template](./downloads/risk-register-template)

## Recommended Usage

1. Use Discovery Questionnaire before proposal scope is finalized.
2. Use Assessment Workbook to convert discovery into risk and readiness findings.
3. Use SOW and WBS templates to align scope, deliverables, timeline and acceptance.
4. Use Risk Register to maintain decision visibility during delivery.
