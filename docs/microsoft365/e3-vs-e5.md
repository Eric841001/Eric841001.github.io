# Microsoft 365 E3·E5·E7 비교

<span id="한국어-요약" />

## 먼저 비교할 세 가지 구성 {/* #executive-summary */}

**E3는 협업과 기본 관리, E5는 고급 보안·규정 준수, E7은 E5에 업무용 Copilot과 에이전트 관리를 함께 도입할 때 검토하는 구성입니다.**

E7에는 **Microsoft 365 E5 + Microsoft 365 Copilot + Microsoft Entra Suite + Microsoft Agent 365**가 포함됩니다. E5에 Copilot만 추가하는 경우와는 구성과 비용이 다릅니다. 필요한 기능과 사용할 사람을 정한 뒤 기존 구독·추가 기능과 비교하세요.

<span id="licensing-verification--2026-10-25" />

## 최신 라이선스 확인

Microsoft의 현재 문서에서는 **Microsoft 365 Copilot을 Microsoft Copilot**, **Microsoft 365 Copilot Chat을 Microsoft Copilot Chat**으로 안내합니다. 기존 명칭은 과거 자료와의 연결을 위해 함께 사용합니다. 앱의 기본 접속 주소도 `copilot.cloud.microsoft`로 변경되므로 네트워크 허용 목록을 확인하세요. [현재 제품명과 접속 요구사항](https://learn.microsoft.com/en-us/microsoft-365/copilot/microsoft-copilot-requirements)을 참고합니다.

비교 대상은 **Microsoft 365 기업용 플랜**입니다. Office 365 E3·E5와 구분하고, Teams 포함 여부와 이용 지역·계약 조건을 확인하세요.

기능 포함 여부는 [Microsoft의 E3·E5·E7 비교](https://learn.microsoft.com/en-us/microsoft-365/copilot/compare-copilot-e3-e5-e7), E7의 구성은 [E7 제품 안내](https://www.microsoft.com/en-us/microsoft-365/enterprise/e7)를 기준으로 정리했습니다. 라이선스를 구매한 뒤에도 사용자 할당과 정책 설정이 필요합니다.

12월 1일 예정된 Copilot 구매 조건과 CSP 신규 Copilot Business 과금 변경은 [시행 전 확인사항](../licensing/july-2026-microsoft-licensing-update#copilot-december-2026-purchase-changes)에 정리했습니다. 현재 구독·사용 권한과 시행 예정 조건을 구분하세요.

**E3 CSP 프로모션:** 10월 27일 시작된 신규 구독 300석 이상 대상 프로모션은 고객 자격 제한이 있으며, 할인 기준도 공개 정가가 아닌 파트너 순가격입니다. [적용 기간과 자격 조건](../licensing/july-2026-microsoft-licensing-update#e3-csp-promotion-2026)을 확인하고 E5·E7 견적과 비교하세요.

## 비교 순서 {/* #decision-framework */}

1. 협업, 기기 관리, 보안 조사, 자료 보호와 AI 사용 중 필요한 업무를 고릅니다.
2. 현재 구독과 사용자별 서비스 플랜, 따로 구매한 보안·Copilot 기능을 확인합니다.
3. E3·E5·E7과 필요한 추가 기능을 같은 요구사항으로 비교합니다.
4. 실제 사용할 사용자 수, 구독료, 사용량 요금과 운영 담당자를 정합니다.

## E3·E5·E7 핵심 비교 {/* #executive-decision-summary */}

| 비교 항목 | Microsoft 365 E3 | Microsoft 365 E5 | Microsoft 365 E7 |
|---|---|---|---|
| Word·Excel·PowerPoint 등 업무 앱 | 포함 | 포함 | 포함 |
| 업무 자료를 참조하는 Microsoft 365 Copilot | 별도 추가 | 별도 추가 | 포함 |
| 계정·접근 관리 | Entra ID P1 | Entra ID P2 | Entra ID P2와 Entra Suite |
| 보안 탐지·대응 | 기본 보호 | 고급 Defender XDR 기능 | E5 기능 포함 |
| 자료 보호·규정 준수 | 핵심 Purview 기능 | 고급 Purview 기능 | E5 기능과 AI·에이전트 관리 연계 |
| Microsoft Entra Suite 전체 | 기본 구독에 미포함 | 기본 구독에 미포함 | 포함 |
| Microsoft Agent 365 | 기본 구독에 미포함 | 기본 구독에 미포함 | 포함 |
| Microsoft Security Copilot | 기본 구독에 미포함 | 적격 고객에 포함 | 적격 고객에 포함 |

Teams는 세 플랜 모두 **구매한 상품에 포함되는지** 확인합니다.

기기 관리 기능도 과거 비교표와 달라졌습니다. 2026년 상용 패키지 개편으로 E3에는 Intune Remote Help·Advanced Analytics·Plan 2가 추가됐고, E5에는 Endpoint Privilege Management·Cloud PKI·Enterprise Application Management도 포함됩니다. E7은 E5 기능을 포함합니다. [공식 개편 안내](https://www.microsoft.com/en-us/licensing/news/2026-M365-Packaging-Pricing-Updates)와 [플랜별 추가 기능 표](/knowledge/licensing/july-2026-microsoft-licensing-update#commercial-packaging-2026)를 확인하고, 기존 Intune 추가 구독과 겹치는지 점검하세요.

 Microsoft Security Copilot과 일반 업무용 Microsoft 365 Copilot은 다른 제품입니다. Security Copilot의 적격 조건과 제공 범위를 별도로 확인하세요.

## E3를 검토할 때 {/* #when-e3-is-appropriate */}

메일·문서·협업과 계정·기기 관리가 중심이고, 고급 보안 기능이 일부 사용자나 특정 업무에만 필요하다면 E3와 필요한 추가 기능을 비교합니다. Copilot 도입이나 Zero Trust 설계만으로 E5·E7 구매가 결정되지는 않습니다.

## E5를 검토할 때 {/* #when-e5-is-appropriate */}

위험 기반 접근 제어, 보안 사고 조사, 고급 자료 보호와 규정 준수가 필요하다면 E5를 검토합니다. 업무용 Copilot은 사용할 사람에게 별도로 추가할 수 있습니다. 이미 쓰는 보안 제품과 겹치는 기능, 정책을 운영할 인력도 함께 확인하세요.

## E7을 검토할 때 {/* #when-e7-is-appropriate */}

E5 수준의 보호와 업무용 Copilot에 더해 **Entra Suite와 Agent 365를 실제로 함께 사용할 계획**이 있는지 확인합니다.

- **Entra Suite:** Internet Access·Private Access, ID Governance, ID Protection과 Verified ID의 프리미엄 기능을 포함합니다. E5의 Entra ID P2와 Suite 전체는 구분해야 합니다. [Entra 라이선스와 Suite 구성](https://learn.microsoft.com/en-us/entra/fundamentals/licensing)을 참고하세요.
- **Agent 365:** 에이전트의 접근·보안·수명주기를 관리할 때 검토합니다. 에이전트 개발 도구나 모든 실행 비용까지 자동으로 해결되는 것은 아닙니다.
- **할당 대상:** 모든 직원에게 일괄 배정하기 전에 해당 기능을 사용할 직무와 운영 담당자를 정하세요. 사용자 수와 실제 이용 범위에 맞춰 혼합 구성을 비교합니다.

## 기능별로 확인할 차이 {/* #e3-vs-e5-capability-view */}

| 확인할 기능 | E3 | E5 | E7 |
|---|---|---|---|
| 조건부 액세스 | P1 기능 | P2의 사용자·로그인 위험 제어까지 검토 | P2와 Suite 기능을 함께 검토 |
| 민감도 레이블·DLP | 수동 레이블과 핵심 보호 기능 | 자동 레이블과 더 넓은 DLP 적용 범위 | E5 보호 기능과 Copilot·에이전트 관리 연계 |
| 고급 감사·eDiscovery | 필요한 추가 기능 확인 | 고급 기능 검토 | E5 기능 포함, 에이전트 활동 관리도 검토 |
| Entra 네트워크·ID 관리 | 필요한 제품 별도 검토 | P2와 Suite 추가 여부를 구분 | Entra Suite 포함 |

특정 기능의 적용 위치, 로그 보존 기간과 미리 보기 여부는 서비스 설명에서 확인합니다. [조건부 액세스](../security/conditional-access)와 [Purview](../security/purview) 문서에서 실제 적용 조건을 이어서 확인할 수 있습니다.

## 실제 포함 기능 확인 {/* #service-plan-entitlement-check */}

- 상품명과 Teams 포함 여부, 사용자별 할당 서비스 플랜을 확인합니다.
- Copilot Chat의 웹 기반 답변과 회사 자료를 참조하는 Microsoft 365 Copilot을 구분합니다.
- 필요한 보안·Purview·Intune 기능을 서비스 설명과 맞춰 봅니다. E7이라는 이름만으로 모든 추가 기능이 포함된다고 판단하지 마세요.
- 이용 지역·클라우드와 순차 배포 상태를 확인하고 대표 사용자로 시험합니다.

## E5+Copilot과 E7의 차이 {/* #e3--add-on-strategy */}

| 구성 요소 | E5 + Microsoft 365 Copilot | E7 |
|---|---|---|
| E5의 업무·보안·규정 준수 기능 | 포함 | 포함 |
| Microsoft 365 Copilot | 추가 구매한 구독으로 사용 | 기본 구성에 포함 |
| Entra Suite 전체 | 별도 구매·기존 보유 여부 확인 | 포함 |
| Agent 365 | 별도 구매·기존 보유 여부 확인 | 포함 |
| Copilot Credits를 쓰는 서비스 | 구독과 사용량 요금을 구분 | 구독과 사용량 요금을 구분 |

E3에 특정 보안 기능만 추가하는 대안도 함께 비교합니다. 이미 보유한 Entra·보안·Copilot 구독을 중복 산정하지 말고, 갱신 시점과 전환 조건을 확인하세요.

## 업무별 선택 기준 {/* #decision-matrix */}

| 필요한 업무 | 먼저 비교할 구성 | 함께 확인할 사항 |
|---|---|---|
| 메일·문서·협업과 기본 관리 | E3 | Teams 상품, 계정·기기 관리 범위 |
| 고급 보안·규정 준수 | E5 또는 E3와 필요한 추가 기능 | 실제 적용할 정책과 기존 보안 도구 |
| 일부 사용자의 업무용 Copilot | 적격 기본 구독과 Copilot 추가 | 사용할 사용자, 자료 접근 권한 |
| 고급 보안·Copilot·Entra Suite·에이전트 관리 | E7과 기존 구독 조합 | Suite·Agent 365 사용 계획과 총비용 |
| 현장 직원·중소기업 | F 계열 또는 Business 플랜도 비교 | 업무·사용자 수와 플랜별 제한 |

## 구독료와 총비용 비교 {/* #business-value-comparison */}

아래는 2026년 10월 27일 미국 공식 제품 안내에 표시된 사용자당 월 환산 가격(USD)입니다. **연간 약정·연간 결제** 조건이며, 한국 구매 견적은 통화·세금·구매 경로·계약 조건을 따로 확인하세요.

| 상품 조건 | E3 | E5 | E7 |
|---|---|---|---|
| Teams 포함 | $39.00 | $60.00 | $99.00 |
| Teams 미포함 | $30.45 | $51.45 | $90.45 |

출처: [E3 가격](https://www.microsoft.com/en-us/microsoft-365/enterprise/e3), [E5 가격](https://www.microsoft.com/en-us/microsoft-365/enterprise/e5), [E7 가격](https://www.microsoft.com/en-us/microsoft-365/enterprise/e7).

총비용은 **기본 구독 + 필요한 추가 구독 + 사용량 요금 + 구축·운영 비용**으로 계산합니다. E7 견적은 E5·Copilot·Entra Suite·Agent 365를 필요한 사용자에게 각각 구성한 견적과 비교하세요. 사용하지 않을 기능까지 비용 절감으로 계산하지 않습니다.

**E7에 Copilot이 포함돼도 모든 AI 작업이 무제한으로 제공되는 것은 아닙니다.** Cowork·Code 등 Copilot Credits를 사용하는 서비스는 사용량과 지출 한도를 확인해야 합니다. 서비스마다 지원하는 사전 구매·종량제·용량 요금 조합이 다르므로 [Copilot Credits 과금 안내](https://learn.microsoft.com/en-us/microsoft-365/copilot/usage-based-billing-overview-copilot-credits)를 확인하세요.

## 계약·운영에서 놓치기 쉬운 항목 {/* #risk-considerations */}

| 확인 항목 | 검토할 내용 |
|---|---|
| Teams 구성 | 포함·미포함 상품과 별도 Teams 구독의 중복 |
| 기존 구독 | 해지·갱신·전환 시점과 이미 보유한 기능 |
| AI 사용량 | 구독에 포함되는 사용과 별도 과금 서비스 |
| 추가 기능 | Teams Premium·Windows 365와 기본 플랜에 없는 Intune 기능의 별도 조건 |
| 운영 준비 | 자료 접근 권한, 정책 담당자, 에이전트 소유자와 변경 승인 |

## 구매 전 질문 {/* #recommended-assessment-questions */}

1. E5의 고급 보호가 필요한 사람과 Copilot을 사용할 사람은 각각 누구인가요?
2. Entra Suite와 Agent 365에서 실제로 사용할 기능은 무엇인가요?
3. 기존 제품을 유지하거나 교체할 비용을 포함했나요?
4. 사용량 요금과 초과 사용을 확인할 담당자가 있나요?
5. 계약 조건과 사용자별 할당·시험 결과를 확인했나요?

## 구성별 검토 방향 {/* #recommended-positioning */}

### E3 {/* #e3-positioning */}

협업과 기본 관리를 바탕으로, 필요한 추가 기능을 정해 비교합니다.

### E5 {/* #e5-positioning */}

고급 보안·규정 준수 요구를 먼저 확인하고, Copilot과 추가 제품의 사용 대상을 따로 정합니다.

### E7 {/* #e7-positioning */}

E5·Copilot·Entra Suite·Agent 365를 함께 사용할 대상과 운영 계획이 있는지 확인한 뒤 묶음 구성을 비교합니다.

## 경영진 검토 자료 {/* #executive-recommendation-model */}

사용자 유형별 필요 기능, 현재 구독, 대안별 연간 총비용, 전환 비용과 운영 담당자를 한 표로 정리하세요. E7의 추가 구성 요소를 실제로 얼마나 사용할지가 구매 판단에 드러나야 합니다.
